# Python Services

This directory contains the core Python modules that power the **LexConnect** application. Each sub‑directory groups related functionality.

## Directory Overview

| Sub‑directory | Description |
|---------------|-------------|
| `embedding` | Code for generating and managing text embeddings. Includes the `EmbeddingManager` class which wraps various embedding providers (e.g., OpenAI, Cohere, Baai). |
| `ingestion` | Data ingestion utilities and notebooks. Holds scripts/notebooks that load raw data, process it, and prepare chunks for indexing (e.g., `rag.ipynb`). |
| `kaggle_dataset` | Helpers for downloading and handling datasets from Kaggle, converting them into a format suitable for downstream processing. |
| `vector_store` | Implementation of vector‑store back‑ends (e.g., Pinecone, FAISS). Provides a unified interface for upserting, querying, and managing vectors. |
| `__pycache__` | Cached compiled Python files generated by the interpreter. |
| `venv` | Virtual environment containing project dependencies. |
| `main.py` | Entry‑point script that wires together embedding, ingestion, and vector‑store components to run the end‑to‑end pipeline. |
| `requirements.txt` | List of Python packages required to run the services. |

---

### Quick Start
1. **Install dependencies**: `pip install -r requirements.txt`
2. **Run the pipeline**: `python main.py`
3. Explore the notebooks in `ingestion/` for data preprocessing examples.
